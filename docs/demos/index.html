Modes: Design · Code · Concept · Debug

Pick how Beast should answer. Concept has Full and ⚡ Short (a 3-line definition, fastest).

  1. Choose Concept (Full): type a question, press Enter
  2. Full answer: concept · use case · diagram · example
  3. Switch to ⚡ Short and ask the same
  4. Short: just the definition, ≤3 lines

2

Screenshot & send: 💻 or ⌘↵

One click (or ⌘↵) grabs the whole screen and sends it with anything you typed. The answer opens at once.

  1. The question is on the screen (LeetCode)
  2. Code mode · type “in Python” · click 💻
  3. Sent screenshot shows next to “Asked:”
  4. Answer: approach · dry run · code · complexity
  5. Empty bar + ⌘↵ works the same

3

Area screenshot: ⌘⇧S

Drag over just the part you want. It waits in the tray so you can add a note or more screenshots, then Enter sends.

  1. Press ⌘⇧S: the screen dims
  2. Drag a box around the problem
  3. The crop waits in the tray (nothing sent yet)
  4. ✎ Add a note for this screenshot
  5. Press Enter: answer follows the note

4

Follow-ups: more text, screenshots and files in the same conversation

Every answer has a follow-up box. Add a screenshot, an area or a file, type a question, and it continues the same thread.

  1. Ask with 💻 (Code · LeetCode on screen)
  2. The screen changes: buggy code
  3. Follow-up box: + Screen and type the question
  4. Send: Q1 stays above with its screenshot
  5. 📎 attach a log file + ask again
  6. + New starts a fresh conversation

5

History: find any answer and continue it

Every question and answer is saved on this computer. Search, filter by mode, copy, or press Continue to keep going.

  1. Open 🕘 History
  2. Search and expand an answer
  3. Press Continue: the whole thread reopens
  4. Ask a follow-up in that conversation

6

Nothing to answer? “Not useful”

If the screenshot has no question, code or error, Beast says so in one line instead of guessing.

  1. The screen is just a desktop wallpaper
  2. Press ⌘↵
  3. One line: ⚠️ Not useful — attach one that shows the question

  1. Choose Debug

  3. Press ⌘↵
  4. Root cause · evidence · fix · before vs after · verify

Design rounds, multiple choice, any language

The same screenshot flow handles system design prompts, MCQs (correct option + why) and questions in Hindi or other languages.

  1. Design: “Design a URL shortener” → full design answer
  2. Concept: an MCQ → the right option + one line why
  3. A question in Hindi → answer in Hindi

9

Solve screen: ⌘⇧O watches and answers new questions

Turn it on and Beast checks the screen every few seconds. Each new question is answered once, in the right mode.

  1. Press ⌘⇧O (or the Solve screen button)
  2. An MCQ appears → found and answered
  3. The screen changes to a coding problem → found too
  4. The same question is never answered twice
  5. Press ⌘⇧O again to stop

Documents: résumé, notes, PDFs, logs

Attach files with 📎 (or drag and drop). Beast reads them and answers using them.

  1. Click 📎 and pick a résumé PDF and notes
  2. They wait in the tray, each can get a note
  3. Ask: “Tell me about yourself”
  4. The answer uses your own résumé

11

Listen + live transcript

Listen hears the meeting and your mic, and answers questions as soon as they are asked. Here the questions are played from the laptop speaker into its own mic (the desktop app reads meeting audio directly).

  1. Click 🎧 Listen (or ⌘⇧M): “Listening…”
  2. The interviewer asks a question (spoken from the speakers)
  3. Beast hears it and the answer opens by itself
  4. Stop with ⌘⇧M · open 💬 Live transcript, turn on the mic
  5. Each line: time · who spoke · text · auto-answer
47s · MP4 · GIF
12

Shortcuts panel: test every shortcut, hide or quit

The ⌨️ button lists every shortcut with what it does. Press one to see a green ✓, or use Try.

  1. Open ⌨️ Shortcuts & controls
  2. Press shortcuts: each row gets a ✓ and the time
  3. Try runs one, same as the keys
  4. Stop Beast: Hide (⌘\) or Quit (asks first)
  5. Terminal commands, click to copy
